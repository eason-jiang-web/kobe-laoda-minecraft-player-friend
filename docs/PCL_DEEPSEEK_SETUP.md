# 用 PCL 的世界 + DeepSeek 跑牢大

角色是**牢大**，游戏里显示的 ID 是 **`Laoda`** —— 因为 Minecraft Java
的用户名只能是 3-16 位英文字母/数字/下划线，中文名服务端不收。人设（说话方式、
性格）和游戏 ID 是分开的两件事，都在 .env 里能改。

这套配置让牢大作为一个**普通玩家**加入你在 **PCL（Plain Craft Launcher）** 里
打开的世界，脑袋用 **DeepSeek**（不是 Hermes，也不需要 Claude）。

```
PCL 启动的 MC 世界  ◄── Mineflayer 机器人 (Laoda = 牢大，另一个玩家)
                              │
                              ▼
                     itto-mc MCP :3001
                              │
                              ▼
               DeepSeek 大脑 (apps/brain-deepseek)
                  只在该反应的时候才被唤醒
```

## 1. PCL 那边怎么做

1. **启动 1.20.6 原版**（`.env` 里 `MC_VERSION=1.20.6`，版本必须一模一样）。
   - 建议用**原版**。Forge / NeoForge 有自定义握手，Mineflayer 连不上；
     纯 Fabric（不带服务端模组）一般可以。
2. 进入你的世界，按 **Esc → 对局域网开放**：
   - **端口**：填 `25565`（必须和 `.env` 里的 `MC_SERVER_PORT` 一致）
     —— 游戏默认给的是**随机端口**，每次都要手动改，忘了机器人就连不上
   - **允许作弊**：**开**
   - 点确定。聊天栏会出现"本地游戏已在端口 25565 上开启"。

   **端口填错 / 世界还没开也没关系**：机器人不会退出，它会一直等（重试间隔退避到
   60 秒一次），每次失败都把"端口该填多少"重新喊一遍；你改好它自己就进来了。
   忘了端口是多少？看那个「指令表」窗口，第一段就写着。
3. **权限（基本不用管）**：牢大**进游戏时会自己确认一遍** ——
   顺手发一次 `/op Laoda`，再发一条 level-2 指令（`/time query daytime`）问出真实权限。
   有权限就安安静静（这是常见情况：开了作弊的局域网世界通常直接就能用指令），
   没权限才在游戏里提示你一句，不会误报。

   真没权限也不影响玩。全部功能（跟随、挖矿、打怪、任务、对话）都不需要权限，
   只有一件事需要它：**离你超过 30 格时用 `/tp` 抄近路**。

   | | 有权限 | 没权限 |
   |---|---|---|
   | 跟着你 | 跑过来 | 跑过来 |
   | 超过 30 格 | **瞬移过去**（快） | 自己走过去（慢，可能被地形卡住） |
   | 挖矿 / 打怪 / 做任务 | 一样 | 一样 |

   没权限的时候他会**自己发现**（发一次 `/tp` 没动就知道），然后改走路，
   不会傻站在那儿发命令。日志里会出现一句提示。

   真要用到权限、他又提示"没权限"时，两条路（都不用记指令也行）：
   - 在游戏里打一次 `/op Laoda`；
   - 或者**退到标题画面**（世界关掉），双击仓库里的 **`给牢大开权限.cmd`** ——
     它自己找到存档、算出离线 UUID、写进 `ops.json`，你一个字都不用打。
     （PCL 开了版本隔离时，把游戏目录写进 `.env` 的 `MC_GAME_DIR` 最稳；
     不写也行，它会先读正在运行的游戏、再扫盘找。）

   想彻底不折腾：`.env` 里设 `TELEPORT_FALLBACK_DISTANCE=0`，他永远不碰 `/tp`。

   **有 op 才有的两个好处**：① 超过 30 格自动瞬移；② 你说「`牢大 传送过来`」他立刻闪到你面前。
4. **保持这个世界开着**。你退出世界，机器人也会掉线（它会自动重连，等你重开）。

> 局域网世界是离线验证（online-mode=false），所以机器人用 `MC_AUTH=offline`
> 就能进来，不需要正版账号。

## 3. 怎么和它玩

它被设计成**很安静**的队友。只有这几种情况才会唤醒大脑（每次唤醒 = 1~2 次
DeepSeek 调用）：

| 触发 | 说明 |
|---|---|
| 你在聊天里提到 **牢大** / **Laoda** / **曼巴**，或者说 "看这个" / "look at this" / "check this out" | 直接喊它 |
| 敌对生物靠近（10 格内且是新出现的） | 会提醒 / 帮忙打 |
| 它自己血量低于 3 颗心、工具快坏了、背包快满了 | 会说 |
| 天黑了、你身边怪物变多 | 会说 |
| 心跳（`HEARTBEAT_MS`，我给你设成 45 秒） | 主动看看情况，有话说就说 |
| **没人理他 + 手上没活** | 自己找活干（自主玩，见下面） |
| **背包里程碑**：木头攒到 128、稀有矿物攒到 10（`MC_REPORT_ITEMS` 随便改） | 主动跟你报一声 |

想让它干活就直接说，比如：

- `牢大 过来` / `Laoda follow me`
- `牢大 帮我砍点木头`
- `牢大 把这附近的铁矿挖了`
- `牢大 看看我指的这是什么`（先指着方块）
- `曼巴`（或者直接甩一句 man, what can I say）
- **`#back`** —— 立刻传送到你身边（**硬命令**，见下）

它会用 MCP 工具真的去做（多步任务走 `set_goal`），做完在聊天里回你一句。

### 硬命令（不走大脑，瞬间生效）

在聊天框里打这几个 —— 它们**不经过模型**，在身体里直接执行：瞬间、稳定、不花 token。

| 命令 | 作用 |
|---|---|
| `#back` | 解除自由活动，**立刻传送到你身边**（要指令权限；没权限会说原因并自己走过来） |
| `#free` | **自由活动**：不跟着你、也不会传送过来，自己去玩（直到 `#back`） |
| `#stop` | **停火**：不再攻击任何生物，并停下手上的动作和当前任务（直到 `#nonstop`） |
| `#nonstop` | **解除停火**：恢复见怪就打 |
| `#attack <名字>` | 去打指定目标：`#attack zombie`、`#attack 苦力怕`、`#attack eason` |
| `#cancel` | **取消当前任务**（只是不干了 —— 还会聊天、还会跟着你，不解停火） |
| `#stay` | **原地待命**：别跟、别乱跑、别干活，就在这儿等着 |
| `#here` | **走到你身边**（自己走，**不传送**） |
| `#quiet` | **闭嘴模式**：你不叫它，它就不主动说话（危险提醒和回话照常） |
| `#talk` | 解除闭嘴，恢复主动聊天 |
| `#profile` | **看它攒下来的经验**：每门本事的熟练度（挖矿/打架/盖东西…按真实成败算）+ 你的习惯 + 记下的教训 |
| `#guide mode` / `#guide off` / `#guide` | **向导模式**：带你走主线、主动报下一步（见下） |

四个模式，开和关各一条命令：

| 模式 | 开 | 关 | 效果 |
|---|---|---|---|
| 自由活动 | `#free` | `#back` | 不跟着你、不传送，自己去玩 |
| 原地待命 | `#stay` | `#here` / `#back` | 不跟、不乱跑、不干活，就站着等 |
| 停火 | `#stop` | `#nonstop` | 不主动打任何生物 |
| 闭嘴 | `#quiet` | `#talk` | 不主动开口 |

> 停火是**硬开关**，解除只有一个办法：`#nonstop`。
> 但 `#attack <名字>` 是**直接命令** —— 停火期间照样会动手打你点名的那个，
> **只是不会顺手解除停火**（打完他会提醒你一句「我还在停火状态」）。
> 换句话说：`#stop` 管的是"别自己乱打"，管不住你点名。
> 打的过程中 `#stop` 能立刻叫停正在进行的攻击。

### 它不会一直问你，还会自己长记性

拿不准的时候它会问你，但**同一件事最多问 3 次** —— 第 4 次会被身体直接拦下来，
那条消息根本不发出去；三次问不出来它就自己拍板干，并用一句话告诉你它怎么理解的。

而且**游戏知识它不问你**：不知道数值、机制、生成条件，会自己去查 wiki（自修笔记 + 中文 Minecraft Wiki）。

每次任务做完它都给自己记一笔（成了/砸了 + 教训），攒下来的东西打 **`#profile`** 就能看：
每门本事的熟练度、你的习惯（常打哪些指令、几点上线、说话长短）、记下的教训和偏好。
数据在 `data/world.db`，边玩边长，**不会被提交**。

细节：

- 只有你能触发（`MC_OWNER_USERNAME`）
- 必须**整行就是命令** —— 「牢大 #back 一下」是普通聊天，不会被吞掉
- `#attack` 支持中文名（僵尸 / 苦力怕 / 骷髅 / 蜘蛛 / 末影人 / 村民 / 猪 / 牛 / 羊 / 鸡 …），
  会自动换最好的武器、走过去打，打完如实汇报：`收拾完了` / `它还没倒` / `够不着` / `附近没看到「xx」`
- 打的过程中 `#stop` 能立刻叫停（战斗技能会当场收手，不会空转）
- `#free` 期间跟随和自动传送都会停；`#back` 一次全部恢复

**他知道自己在什么状态**：世界快照里会写
`modes: 自由活动(#free：不跟着他、不会传送) + 原地待命(#stay：就在这儿等，不跟也不乱跑) + 停火(#stop) + 闭嘴(#quiet)`，
所以你在 `#free` 期间说「过来」，他会回你「我在自由活动，打 #back 才回去」——
而不是答应一声然后原地不动。

**记不住没关系**：

- **启动时终端里会把上面这些全列出来，而且每条带完整用法**（出口是哪个、有什么坑、
  需要不需要权限都写在命令名后面）—— 同样从命令表自动生成，加命令自动出现，不会和文档脱节
- 游戏里打 `#help` 出一行速查表（快查用；详细说明看终端那段）
- **他眼里的东西是中文的**：背包、方块、生物名全部显示成你在游戏里看到的那个名字
  （橡木原木 / 粗铁 / 深层铁矿石 / 僵尸），名字直接从他本机 Minecraft 的语言文件读，
  所以逐字一致。他跟工具说话时也认中文 —— 说「挖点橡木原木」和说 `oak_log` 一样。
- 菜单按 `1` 开玩时会**额外弹一个「指令表」窗口**，里面第一行就是"别忘了 /op Laoda"，
  下面每条命令的用法、出口、坑都列好了 —— 忘了就瞟一眼，关了也不影响游戏（菜单按 `3` 能再开）

想加别的硬命令，改 `apps/mc-bot/src/chat-commands.ts` 里的 `COMMANDS` 表就行 ——
一条命令一个对象，带说明和回复语；终端提示、`#help`、文档三处都会自动跟上。

> 顺带一提：说「`牢大 传送过来`」也还是有效的，那条走大脑
> （慢一两秒，但他会顺嘴贫一句）。`#back` 是"别废话，过来"。

### 向导模式（`#guide mode`）

打 `#guide mode`，他从"搭子"切成"向导"：

- **内置原版主线 10 步**：撸树 → 工作台 → 石器 → 火把 → 铁器 → 钻石 → 下界之门 → 下界要塞 → 末影之眼/要塞 → 末地打龙
- **自动判断你到哪一步**（看背包和维度），所以他的提示是**跟着你的进度走的**，不是背课文
- **主动报点**：向导模式下他的"心跳"变成"看一眼进度、该提示就提示" —— 不用你问
- `#guide` 随时看进度和下一步（**纯计算，不花 token，秒回**）；`#guide off` 下班

**他也因此更懂规矩**：世界准则（工具等级、亮度刷怪、挖矿 y 坐标、传送门、床在末地会炸……）
是**常驻在大脑的 system prompt** 里的 —— 静态前缀能吃到上下文缓存，所以常驻不贵。

实测效果（不同进度问"接下来干嘛"）：

| 进度 | 他说 |
|---|---|
| 刚开世界 | 先撸树，你空手我空手，走起 |
| 有木头石镐 | 走铁器时代！带火把，目标 y≈15 挖铁 |
| 有铁器 | 下一站钻石，往下挖到 y≈-59，带桶水防岩浆 |

> ⚠️ 他看的是**自己的背包**，不等于你的 —— 所以他可能会问一句"你现在有啥"。
> 想纠正就直接说，别让他瞎指挥。他是搭子，不是教官。

#### 攻略是"活"的（弹性判断）

他**不背课文** —— 数字是区间，判断看当下：

- **数字是区间**：说 y≈15 就是 10~56 都行；顺着矿洞和地形走，比死磕坐标强
- **路过就判断**：每 15 秒扫一眼附近的矿，三件事一起看 —— ① 我挖得动吗 ② 我还缺吗 ③ 值不值得绕路：

| 情况 | 他怎么做 |
|---|---|
| 挖得动 + 还缺 | **就地挖了**，挖到跟你汇报 |
| 早就够了 | 记个坐标就走（"你都 40 个钻石了还挖啥"） |
| 挖不动 | **记下来**（`remember_location` kind:"ore"），等有好镐子再回来 |

- **以后能挖了会提醒**：你之前标记的矿，一旦它手上镐子够了、而且就在 64 格内 → 主动提醒你"那个钻石矿现在能挖了，去不去？"（5 分钟最多提醒一次，不念叨）
- **物资盘点**：每次自己排活、每次向导报点，都会带上"**还缺什么 / 早就够了什么**"，
  所以不会出现"铁都 400 个了还去挖铁"这种事

**目标按在线人数缩放**（有人一起来玩，目标就翻倍）：

| 物资 | 每人 | 为什么是这个数 |
|---|---|---|
| 铁 | **100** | 一套铁装备 24，**一个铁砧就 31**，再加桶/剪刀/铁轨 —— 真会用完 |
| 金 | 64 | 金苹果 8 锭/个，动力铁轨 6 锭/16 根，下界合金每锭还要 4 金 |
| 钻石 | 64 | 整套装备 24 + 全工具 9 + 附魔台 2 ≈ 40，留一套重造的余量 |
| 下界合金 | 32 | 1 锭 = 4 碎片；全身 4 件 + 3 工具 = 7 锭 = 28 碎片 ≈ 14 个残骸，够肝了 |
| 木头 / 石头 | 128 | 工具 + 箱子 + 盖个小屋，两组打底 |
| 煤 / 木炭 | 64 | 1 煤 = 4 火把 → 256 根，够把矿洞点成白天 |
| 红石 | 64 | 机关和药水都是成组烧的 |
| 青金石 | 32 | 附魔一次 1~3 个 |
| 吃的 | 32 | 跑一趟远门消耗不小 |

判定用的是"**≥ 目标 × 1.25 才算囤过头**"，所以不是一到线就唠叨。举例（同一个 400 铁）：

| 场面 | 判定 |
|---|---|
| 1 人玩 | 目标 100 → **早就够了，别囤** |
| 2 人玩 | 目标 200 → 早就够了 |
| 4 人玩 | 目标 400 → **刚好，不算多** |

想改数值：`packages/shared/src/needs.ts` 里的 `PER_PLAYER_WANT`（每人份，一处改全部生效）。

#### 语气是硬要求：**只建议，不催**

上限不是任务清单 —— 它是"**这东西现在还值不值得特意绕路**"的参考。代码里
`valueReport` 的结尾就写着「不是任务清单；他不想弄就别提」，世界准则里也写死了
「永远只建议、不催促；他说不想弄、或者正忙着，就别再提这件事」。这是防止模型把上限当 KPI 去冲。

#### 每个物品都评（不只是那几样）

认识的物品在 `packages/shared/src/value.ts` 的规则表里（约 30 条覆盖几百种）；
**不认识的也不会漏** —— 按名字兜底（`_ore` → 稀有、`_ingot` → 实用、`_log` → 常见…）。

标尺不在主观喜好上，而在**游戏机制**上：

1. **获取难度**：矿石每区块产出密度、能不能农场化、要几步合成
   （泥土要多少有多少 → 钻石约 1 脉/区块 → 远古残骸 1~3 个/区块还得烧 → 下界合金锭 = 4 碎片 + 4 金锭）
2. **用途广度**：能解锁多少事（铁能出工具 + 装备 + 铁轨 + 铁砧 + 桶；泥土只能盖房种地）
3. **当下情况**：你手上已经有多少、离上限多远

> 说一下查资料的结果：我本想直接照抄攻略，但搜出来的是多语言噪音；
> 去查 Minecraft Wiki 发现它的 **Rarity 页其实是「名字颜色」**（绿宝石都算 Common），
> 拿来当生存价值会闹笑话。所以最终按 **Ore / Renewable resource 这些机制** 推的。

#### `#value` —— 看评估，也能改上限

```
#value                → 一行总览（哪样值钱、哪样溢出）
#value 铁             → 单件详情（价值分、用途、你的数量、上限、建议）
#value 铁 400         → 把铁的上限改成 400（绝对总数，不再乘人数）
#value 铁 0           → 铁改成不限量
#value 铁 默认        → 清除自定义，回到默认表
```

中文、物品 id 都认（铁 / 铁锭 / 钻石 / 下界合金 / 木头 / raw_iron / diamond…）。
改完会**存进 `data/value-caps.json`**，重启不丢；而且会同步进世界快照，
所以**向导、自主玩、路过矿石的判断全都跟着变** —— 不是只有一个命令认得这个数。

实测一遍（同一个背包，铁 400）：

```
#value 铁        → 铁：实用·21 分｜你有 400，上限 100 → 早就溢出了（400/100），纯占地方
#value 铁 400    → 行，铁的上限改成 400 了。铁：实用·42 分｜你有 400，上限 400（你自己定的）→ 够了
#value 铁 默认   → 行，铁的上限还原成默认了。… → 早就溢出了（400/100）
```

注意**分数跟着动**（21 → 42）：上限调高，这东西的"当下价值"就回升 —— 因为评估标准本来就是
"值不值得特意去弄"，不是物品的固有属性。

#### 一行总览

```
值钱：ancient_debris×6、diamond×60、blaze_rod×4；溢出：raw_iron×400、oak_log×300（上限只是参考，不催你）
```

逐件评分（**分数会随持有量衰减** —— 够了的东西价值自动掉）：

```
 96 分  ancient_debris   relic      值得顺手拿（6/32）
 85 分  diamond          precious   值得顺手拿（60/64）
 57 分  elytra           relic      够了（1/1），不用特意去弄
 21 分  raw_iron         useful     早就溢出了（400/100），纯占地方
  6 分  oak_leaves       chaff      要多少有多少，别为它绕路
```

实测三条路的原话（确定性输出，不是编的）：

```
石镐遇到钻石 → 挖不动：diamond_ore 需要铁镐，你手上最好的是石镐。
             → 用 remember_location 记下来（kind 填 "ore"，note 填 "diamond_ore"），
               等他有了镐子我再来；顺手跟他说一声「看到个 diamond_ore 挖不动，先记着」

铁镐 + 已有 40 钻石 → 但你已经 40 个钻石了，早就够用 —— 除非他明确想要，不然别绕路

铁镐 + 缺口钻石   → 你手上是铁镐，挖得动，而且钻石还缺（0/3）。
             → 顺手挖了它（dig_at 到那个坐标），挖到跟他说一声
```

### 让他用指令栏（可选，需要 op）

他能像你一样在聊天框里打 `/` 指令 —— `/time set day`、`/weather clear`、`/give eason diamond 3`、
`/summon cow` 之类。你说「天黑了」他会自己去把时间调亮，而不是干等你。

**默认只放行一批安全好玩的**：

`time` · `weather` · `say` · `me` · `list` · `seed` · `difficulty` · `summon` · `give`

没放行的（`fill` / `setblock` / `kill` / `gamemode` / `op` / `stop` …）会被**拒绝**，
并且告诉他能用哪些 —— 所以他不会（也不能）`/fill` 把你的房子填平、`/stop` 把服务器关了。

想改：`.env` 里 `MC_ALLOW_COMMANDS` 用逗号列出来，或者写 `*` 全部放行（**那它就能拆家，慎用**）。

> 他会**读服务器的回话**：成功、权限不足、指令不存在，都会如实告诉你 ——
> 不会出现"嘴上说调好了、实际没调"的情况。
>
> 前提是有指令权限（局域网开了作弊一般就有）。真被拒了，他会把服务器那句话原样说给你听。

### 语音（已删除）

>

> （Win+H）把话打进聊天框 —— 那对机器人来说和打字完全一样。
>

### 跟着你干一样的活：`#follow play`

它看一眼你现在在干嘛，然后自己去干同类的活：

| 你在干嘛 | 它怎么判断 | 它会去做 |
|---|---|---|
| 砍树 | 正对着木头，或者手上拿着斧子 | 跑去找附近的树，从下往上砍，砍到够数 |
| 挖矿 | 正对着石头/矿，或者手上拿着镐子 | 挖你正对着的那种方块 |
| 打架 | 旁边有怪 | 上来帮你打 |
| 盖东西 | 正对着工作台/箱子/建材 | 去帮你备料 |
| 看不出 | —— | 老实跟着你，让你补一句（"一起砍树"也行，只是走大脑慢一点） |

**它干活卡住的时候会自己想办法**（不用你教）：

| 卡在哪 | 它怎么自救 |
|---|---|
| 树顶那几格够不着 | 先跳，再钻进树干，最后**垫方块往上爬**（垫完会确认自己真的上去了） |
| 矿洞里黑得看不见 | **自己插火把**（每挖 6 格检查一次光照，够亮就不浪费） |
| 目标在墙后面 | **把挡路的那两格挖穿**（不会为了够一块石头绕地球一圈） |
| 走不动 / 被卡住 | **脱困**：蹦一下往前蹭，还不动就把身边挡路的方块挖掉再试 |

这四条都有"真的做到了吗"的验证 —— 垫了没上去、火把没插亮、方块没挖掉，都会老实算失败，
不会出现"嘴上说弄好了、实际没弄"的情况。

### 他会盯着你的动作（不只是等你说）

搭子最该有反应的是"你刚干了什么"。现在这些它都会注意到，而且**自己判断怎么接**（不是念稿）：

| 你干了什么 | 它的反应 |
|---|---|
| **被打** | **优先叫醒**：先看是谁贴着你，该还手还手、该扔吃的扔吃的 |
| **死了** | **优先叫醒**：先安慰，再主动问"要不要我去把掉落物捡回来"（掉落物几分钟就没了） |
| **捡到钻石 / 远古残骸** 这类 | 夸一句 —— 它是真看着你挖的 |
| **完成进度** | 恭喜 + 顺手点一句下一步 |
| **丢下东西**（在你脚边） | 知道那多半是给它的：走过去捡起来、说一句收到了 |
| **睡下 / 起床** | 别吵你 / 打个招呼 |
| **上线 / 下线** | 打招呼 / 记一下你最后在哪，等你回来 |

怎么做到的（两类来源）：

- **mineflayer 事件**：被打（`entityHurt`）、捡起东西（`playerCollect`）、完成进度（`advancement`）、
  丢下东西（`itemDrop` + 判据"掉落物出现在你 6 格内"）
- **服务器播报文字**：死亡、睡觉、上下线这些**没有事件**，只有聊天栏那一行
  （"eason 被 僵尸 杀死了" / "eason 完成了进度 [探索时间]"），中英文都认

分寸也定好了：紧急的（被打 / 死了）走**优先通道**（忽略全局限流，用聊天的短冷却）；
其余的走普通通道可以等一等；只认**你**的动作；事件 60 秒过期、最多留 24 条 ——
不会攒一堆积压旧事突然全倒出来。

> 看不到的：mineflayer 不暴露**别人的血量**，所以只知道"你被打了"，不知道你还剩几点血。
> 逐格挖矿也没跟（那会变成刷屏）；想要"你挖到矿就说一句"可以再加一层过滤。

### 他会主动回你（实时对话）

`.env` 里 `MC_CHAT_REPLY_ALL=true`：**你在游戏里说什么他都回**，不用每次喊名字。
喊名字（牢大 / 曼巴 / what can i say）依然有效 —— 那是"必须理我"。

聊天走**快通道**：

- `BRAIN_CHAT_COOLDOWN_MS=1200`：有人跟你说话时只等 1.2 秒（普通事件要等 6 秒）
- 聊天的唤醒**不受慢循环全局限流**（别的触发要排队，回话不排队）
- 大脑忙的时候，**插队的聊天会顶掉排队中的普通事件**（不会因为正在做心跳就不理你）

想更像打电话：把 `BRAIN_CHAT_COOLDOWN_MS` 调到 500（代价是 token 花得快）。

### 他会自己玩游戏（自主玩）

`.env` 里 `MC_AUTOPLAY=true`：**没人理他、也没有正在跑的任务时，他自己排活干。**

- 他会收到一句"自由活动：你自己决定干点什么"，并附上：**主线进度**（走到第几步、
  这一步该干嘛）+ **背包清单** + **现在材料够开工的工程**（见下）
- 然后自己挑：推进度 / 砍树囤料 / 挖矿脉 / 探路 / 盖东西 / 整理箱子
- 决定完用 `set_goal` 交给身体在**后台跑**（不占用对话），做完会回来跟你汇报
- 真的没什么想干的，他就安静跟着你，不硬找事

触发频率 = `HEARTBEAT_MS`（现在 45 秒）。想更勤快调小，想省 token 调大或设 0 关掉。

#### 他自修过一遍 wiki（知识笔记）

跑一次（约 2 分钟，57 个条目）：

```powershell
bun run study:wiki            # 只学没学过的，可以反复跑
bun run study:wiki -- --force # 全部重学
bun run study:wiki -- --topic 僵尸   # 只补一条
```

它做两件事：① 去中文 Minecraft Wiki 取条目摘要；② 把摘要交给 DeepSeek，让它自己蒸馏成
**能改变行动的要点**（数值/条件/顺序）。产物：

| 文件 | 给谁看 |
|---|---|
| `data/wiki/notes.json` | 大脑：要点常驻系统提示词最前面（稳定前缀，吃到上下文缓存），原文按需用 `wiki_notes` 工具翻 |
| `data/wiki/notes.md` | **你**：直接读它到底学了什么 |

学到的样子的（57 条里的几条）：

```
### 僵尸
- 天空光照≤7且方块光照0才刷僵尸，蘑菇岛和深暗之域除外
- 沙漠露天刷僵尸80%变尸壳，非尸壳5%变僵尸村民
- 5%概率刷幼年僵尸，速度快50%，能穿1×1格空间
### 刷怪塔
- 挂机点需离任何可生成方块至少128格，否则生物会刷在塔外
### 钻石
- 时运每级+1最大掉落，时运III最多4个
```

- 常驻部分约 **3.6k tokens**，但它在提示词最前面 —— DeepSeek 的上下文缓存对它几乎免费
- 细节问原文：大脑自己调 `wiki_notes`（离线、瞬时），比现查 wiki 快
- **宁可查不到，也不学假知识**：wiki 全文搜索对「挖矿技术」这种词会返回《基岩版1.20.40》，
  所以加了相关性闸门（标题和主题必须沾边），不沾边就当作没查到 —— 实测挡掉了一条假笔记

#### 不懂的事他会自己去查 wiki

模型自带常识，但细节会记混、也会过时（生成条件、具体数值、版本差异）。所以给它一个
`wiki_lookup` 工具：拿不准就查**中文 Minecraft Wiki**（zh.minecraft.wiki），返回一段
纯文本摘要 + 来源链接，然后按查到的东西说话 —— **不许编**。

- 实测（真查、真返回）：`僵尸` → 5486 字（"内部天空光照 ≤7 且方块光照为 0 才生成，蘑菇岛除外"）、
  `刷怪塔` → 《Tutorial:刷怪塔》4090 字、`铁傀儡` → "村民睡过觉且在工作…才会生成"，340~630ms
- 先按条目标题取（大多数就是词本身），没有再全文搜索；正文截断到 1500 字，够讲清机制又不炸上下文
- 同一个词一小时内只真正请求一次（有缓存），断网/查不到会老实说"没查到"，不会瞎编
- 提示词里写明了：**基础常识不用查**，只有容易记混的细节才查

#### 他会看进度，也会想着盖设施

每次自主玩（以及每次 `#guide`）都会算一遍**工程评估**：拿它自己的背包去对一遍开工条件，
把结果原样写进给大脑的提示里。现在认这些：

| 工程 | 开工条件（背包里够就行） |
|---|---|
| 小麦农场 | 锄头 + 种子×3 + 泥土×8 |
| 基地储物间 | 箱子×2 + 熔炉×2 + 圆石×32 + 火把×4 |
| 动物圈养 | 小麦×3 + 栅栏×6 + 栅栏门 |
| 甘蔗/竹子农场 | 甘蔗或竹子 + 沙土×4 + 水桶 |
| 刷怪塔 | 圆石×64 + 火把×8 + 武器 |
| 下界传送门 | 黑曜石×10 + 打火石 |
| 附魔台 | 钻石×2 + 黑曜石×4 + 书 |
| 铁傀儡农场 | 铁块×3 + 铁锭×4（另外要村民 —— 所以它会说"得先去村庄"） |

提示里会写清"能开工的"和"还差什么"（比如 `刷怪塔：还差 火把 ×8`），
**但只是建议**：他不想盖、或者在打仗赶路，就别提；缺料也不当任务催。

进度判断也顺手修聪明了：以前是"第一件没做的事"（背包里今天没带原木，就会被告诉"先去撸树"），
现在是"已经做到的最后一步再往前一格" —— 拿着钻石镐的后期玩家不会再被劝去撸树。

想随时问一句：游戏里打 `#guide`（顺带报现在材料够盖什么），
或者大脑自己调 `assess_progress` 工具（纯计算，不花 token、不碰世界）。

### 任务系统：会自己去做，也知道做没做完

你交代的事会变成**可验证的任务**，不是「技能跑完就算数」：

| 你说 | 他会做什么 | 什么时候才算完成 |
|---|---|---|
| 「去找个村庄」 | 跑 `explore_for` 技能：走出去绕圈找（**村民 / 铁傀儡 / 钟 / 堆肥桶 / 讲台**都是线索），每段腿长 ≤28 格所以是**真走**不是传送 | 找到 → 把坐标带回来并走过去；绕完没找到 → 老实说没找到 |
| 「给我 32 个木头」 | `collect` 任务：自动挑工具（木头→`chop_tree`，矿石→`mine_vein`）一轮轮跑 | **背包里真的有 32 个**才算完成 |
| 「把你那把斧头给我」 | `deliver` 任务：走到你面前丢下 | **你真的捡走了**（地上掉落物消失）才算完成 |
| 「跟着我」 | follow | 立刻完成 |

- 跑任务时**跟随会自动让位** —— 不会一边做任务一边粘着你
- 你让他找村庄，他就真的去找，不会拿「跟着你」糊弄
- **背包里不够就直接说实话**：`背包里不够：stone_axe×1（先 collect 或者去箱子里取）`
- 每轮采集都会重新数背包；弄不到就承认：`弄不到更多了：0/8 diamond`

**任务结束 = 一条「任务结算」把他叫醒**：他会跟你汇报结果（拿到了多少 / 为什么没成），
然后**回到空闲状态**，等你下一句话开新任务 —— 这就是「一个任务结束再开下一个」的循环。

### 记忆 & 训练数据（越玩越熟，也越玩越准）

**记忆**（存在 `data/world.db`，重启不丢）：

| 记什么 | 工具 |
|---|---|
| 地方 | `remember_location` / `recall_locations` |
| 箱子内容 | `index_chest` |
| 笔记 | `remember_note` / `recall_notes` |

而且**记忆会自己出现在提示里**：每次"自己找活干"时，你记的笔记 + 去过的地点会直接写进它的
提示（不用它自己去查库），所以它做计划时会带着"eason 想要个城堡""基地在哪"这些上下文。

**训练数据**（存在 `data/training/`）—— 每被唤醒一次就落一条：

| 文件 | 内容 |
|---|---|
| `turns-YYYY-MM-DD.jsonl` | 发生了什么 → 它调了哪些工具（**含每个工具的真实返回**）→ 说了什么 → 耗时 |
| `labels.jsonl` | 你的 `#good` / `#bad` 打分 |
| `dataset.jsonl` | `bun run train:export` 合并出来的数据集（打分贴到对应回合上） |

**怎么用**：玩的时候觉得它这波做得好就回一句 `#good`，做得蠢就 `#bad`（对着"刚才那一轮"打）。
攒一阵之后：

```powershell
bun run train:export
```

会打一份体检报告（回合数、开口比例、平均耗时、工具使用排行、你打了多少分），
并写出 `dataset.jsonl` —— 之后想微调或评估，直接读这个文件。

> 关掉/调小：`.env` 里 `BRAIN_TRAIN_LOG=0` 完全不写；`BRAIN_TRAIN_FULL=1`
> 会连完整提示一起存（训练对更完整，但文件大很多）。

### 他的记忆（越玩越熟）

| 记什么 | 工具 | 例子 |
|---|---|---|
| 地方 | `remember_location` / `recall_locations` | 基地、矿洞、传送门坐标 |
| 箱子 | `index_chest` | 哪个箱子有什么，取东西时能找到 |
| **笔记** | `remember_note` / `recall_notes` | 计划、承诺、你的喜好："eason 想要个城堡" |

全存在 `data/world.db`，重启不丢；`itto://memory/world` 能一次读全。

## 5. 它到底有哪些本事

大脑每次被唤醒时，会现场从 MCP server 读取能力清单，包括：

- **移动**：`move_to`、`look_at`、`stop`
- **挖 / 放**：`mine_block`、`place_block`、`dig_at`、`mine_many`
- **物品**：`equip`、`drop_item`、`craft_item`、`collect_drops`
- **感知**：`find_blocks`（支持 `any_log` / `any_ore` 这类别名）、`look_detect`、`nearby_blocks`
- **说话**：`chat`
- **多步任务**：`set_goal` / `cancel_goal` / `run_skill`
  （`chop_tree`、`mine_vein`、`combat_assist`、`scout_ahead`、
  `build_helper`、`fetch_item` …）
- **记忆**：`remember_location`、`recall_locations`、`index_chest` +
  资源 `itto://memory/world`（存在 `data/world.db`，重启不丢）

大脑还能读 `itto://state/current.txt`（实时世界快照），所以它说的话是基于
当下的真实情况，不是猜的。

## 6. 换 Minecraft 版本

换版本是**两处一起改**，少改一处就连不上：

1. **PCL 里**换成目标版本启动（想玩 1.21.4 就启动 1.21.4）。
2. **`.env` 里**把 `MC_VERSION` 改成**一模一样**的字符串：

   ```
   MC_VERSION=1.21.4
   ```

3. 确认 mineflayer 认识这个版本：

   ```powershell
   bun run mc:versions
   ```

   它会告诉你 .env 里当前版本能不能用，并列出现在支持的正式版。
4. 重开世界 → 重新"对局域网开放"（端口还是 25565）→ 重启 `bun run bot`。

注意事项：

- **差一个小版本都连不上**：1.21.3 的机器人进不了 1.21.4 的世界，反过来也一样。
- 目前能连的正式版有 **55 个（1.7 ～ 1.21.11）**；**快照版 / 预览版不支持**。
  写了个没有的版本时，启动会直接告诉你最接近的可用版本，比如：
  `MC_VERSION="1.21.2" is not a Minecraft version mineflayer can speak. Closest supported release: 1.21.3.`
- **存档升级不可逆**：单机存档被新版本打开过之后，老版本就回不去了（游戏会提示）。
  换大版本之前先备份 `saves` 文件夹。
- **模组要跟着换**：原版换原版没影响；Fabric 换版本要换对应版本的 Loader / API。
  Forge / NeoForge 依然连不上（Mineflayer 不认它的握手），这条不随版本变化。
- 机器人名、喊它的词、DeepSeek 配置都跟版本无关，**不用动**。

## 7. 成本 / 节奏

- 默认模型 `deepseek-v4-pro`（API 只认 `deepseek-flash` / `deepseek-v4-pro`，两个都支持工具调用；想更快更省就换 flash）。**必须**用支持工具调用的：不支持的话它只会聊天、不会动手（老的 `deepseek-reasoner` 就是这样）
  function calling，只能聊天不能动手。
- 一次唤醒 ≈ 1~2 次请求，几千 token 输入 + 一句话输出。
- 想更省 / 更安静：
  - `HEARTBEAT_MS=0`：关掉"没事找事"的心跳，只保留事件触发
  - 调大 `BRAIN_COOLDOWN_MS`（默认 10000 = 10 秒内只唤醒一次）
  - `BRAIN_MAX_STEPS` 调小（默认 6，即一次唤醒最多 6 轮工具调用）
- 想看每次唤醒的完整过程：`.env` 里加 `LOG_LEVEL=debug` 和 `BRAIN_DEBUG=1`。

## 8. 出问题怎么办

| 现象 | 原因 / 处理 |
|---|---|
| `ECONNREFUSED 127.0.0.1:25565` | 世界没开局域网、端口不是 25565，或你已经退出了世界 |
| 连上秒断 / Unsupported protocol version | PCL 里启动的版本和 `MC_VERSION` 对不上（见第 6 节） |
| 启动就报 `is not a Minecraft version mineflayer can speak` | 这个版本 mineflayer 不认识，按提示换成它给的那个版本 |
| 一直卡在 logging in 或掉线 | 版本是 Forge / NeoForge；换原版（或纯 Fabric） |
| 机器人进来了但不动 | `MC_OWNER_USERNAME` 和你的游戏名不一致（大小写敏感） |
| DeepSeek 报 401 | key 不对，改 `.env` 里的 `DEEPSEEK_API_KEY` |
| DeepSeek 报 402 | 账户余额不足 |
| 它一句话都不说 | 正常，它默认很安静；说一句 "牢大" 或 "曼巴" 试试，或把 `HEARTBEAT_MS` 调小 |
| 想换名字 | 游戏 ID 改 `.env` 的 `MC_BOT_USERNAME`（只能 ASCII），喊它的词改 `MC_WAKE_WORDS`；人设改 `packages/shared/src/prompts.ts` |
| 一直 `reconnecting in ...` | 世界关掉了；重开局域网后它会自己连回来 |

## 9. 和朋友一起玩（不在同一台电脑）

机器人要连的是**能连到那个世界的地址**：把 `.env` 里的 `MC_SERVER_HOST`
改成对方开局的机器 IP（推荐 Tailscale 或同一局域网），端口填对方开放局域网时用的端口。
大脑和 MCP 依然跑在你自己的机器上。

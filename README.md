# 牢大 · Minecraft 陪玩 AI

> 一个会**跟着你玩**的 AI 搭子：进你的世界、跟着你、帮你打怪挖矿、记住你的基地，
> 用中文跟你聊天，还会**看你正在干嘛、跟着干一样的活**。

不是攻略助手，不是教程机器人。是那个你挖矿时在旁边絮叨、你被打时冲上去、你死了帮你捡东西的兄弟。
人设是「抽象战神」，招牌台词：**What can I say? Mamba out!**

## 它现在会做什么

| | |
|---|---|
| **跟着你** | 15Hz 跟随 + 脱队自动抄近路（有 op 就瞬移，没有就走过去） |
| **听你说话** | 游戏聊天栏说什么都接（不用喊名字），也能听懂「去挖点铁」「跟着我」「给我 32 个木头」 |
| **真的去做** | 砍树、挖矿脉、探路、找村庄、打怪、取东西、丢东西给你 —— 多步任务在后台跑，做完回来汇报 |
| **会看进度** | 知道主线走到第几步、这一步该干嘛；还会算**现在材料够盖什么**（农场/储物间/刷怪塔/传送门/附魔台/铁傀儡农场…），缺料会列清单 |
| **跟着你干一样的活** | \`#follow play\`：看你手里拿的、正对着的方块，然后自己去砍树 / 挖矿 / 打架 |
| **盯着你的动作** | 你被打/死了优先反应；你捡到钻石、完成进度、丢东西给它、睡下、上下线它都知道 |
| **自修过 wiki** | 跑一次 `bun run study:wiki`，它读 57 个中文 Minecraft Wiki 条目、自己蒸馏成要点常驻记忆；细节随时用 `wiki_notes` 翻原文 |
| **物品名是中文** | 从你本机 Minecraft 的语言文件读（橡木原木 / 粗铁 / 深层铁矿石），和你在屏幕上看到的逐字一致 |
| **硬指令** | `#back` 瞬移到你身边、`#free` 自由活动、`#stop` 停火、`#attack 僵尸`、`#value 铁 400` 改物资上限、`#guide` 看进度… 不走大脑、瞬间生效、不花 token |
| **不烦你** | 拿不准的事才问，而且**同一件事最多问 3 次** —— 三次问不出来就自己拍板开工，还会说一句它怎么理解的 |
| **边玩边学** | 自动攒你的习惯（常打哪些指令、几点上线、说话长短）+ 它自己每门本事的成败；`#profile` 随时看它现在什么水平 |
| **不复读** | 同一句话、或者同一个开场白（「收到 man，…」这种）连着用就会被拦；**该沉默时真的沉默** —— 不再汇报"我在保持安静" |
| **会闲聊** | 闲下来不只是自己找活干 —— **干活和陪聊两种心情轮流来**；你在旁边的时候它会主动搭话、吐槽、问你今天想干啥 |
| **被调教** | `#good` / `#bad` 给刚才那轮打分，写进 `data/training/` 训练日志 |

## 它会自己长记性

同一个存档玩久了，它不该每天从零开始。三套东西在后台默默攒：

**① 你的习惯** —— 身体自动记，**不花模型钱**

你打过的每一条 `#指令`、说过多少话、平均一句几个字、习惯几点上线：来一句话就记一笔，不用额外回合。
攒够了写进 `data/profile-digest.txt`，下次唤醒时进它的系统提示词。

**② 它自己的熟练度** —— 按**真实成败**算，不是自我感觉

每个任务做完都结算：算哪门本事（挖矿 / 采集 / 打架 / 盖东西 / 探路 / 种地 / 合成 / 认路），成了还是砸了。
分数带平滑，样本少的时候不吹：

```
5 次全成 → 8 分        0 次尝试 → 中性 5 分        6 次只成 1 次 → 4 分
```

它还会自己写教训和偏好（`note_experience`：「晚上别在平原乱走」「他喜欢挖矿，不喜欢下矿洞」）。
下次碰到同样的情况按经验来，而不是重新踩一遍坑。

**③ 它不会烦你** —— 关键是**先分清该问谁**：

| 它不知道的 | 走哪条路 |
|---|---|
| **游戏怎么玩**（数值、生成条件、机制、配方、附魔） | **自己查**：`wiki_notes`（自修笔记，离线秒回、免费）或 `wiki_lookup`（现查中文 wiki，带回来源）—— **不问你** |
| **你想要什么**（「那边」是哪边、「随便弄点」是弄啥、你的口味） | `ask_player` 问你，而且**同一件事最多 3 次**（10 分钟窗口） |

第 4 次会被身体直接拦掉 —— 那条消息根本不发出去，它拿到的是「已经问过 3 次了，别再问，按最合理的假设开工」。

另外 10 分钟内所有话题加起来最多问 5 次，防止它换个说法接着追问。

> 它宁可自己拍板干错一次，也不站在那儿问第四遍。这是刻意的：只会追问的搭子会变成审讯室。

游戏里打 `#profile` 就能看到它现在的水平和记住的东西。数据存在 `data/world.db`（**不会被提交**）。

## 实测数据

下面每个数字都是**在一台普通 Windows 机器 + 一个局域网世界**里真跑出来的，并注明怎么测的 —— 不是估算。

### 反应速度

| 环节 | 实测 | 怎么测的 |
|---|---|---|
| wiki 查询 | 每次 **340–630ms**（同一词 1 小时内走缓存） | zh.minecraft.wiki 的 MediaWiki API |
| 自修一条 wiki | **1.3–2.4 秒**（取摘要 + 模型蒸馏成要点） | 57 个条目约 2 分钟跑完 |
| 你说一句 → 它回一句 | 约 **1–3 秒** | 模型一轮 + 工具调用（估算，不是仪器测的） |

### 语音相关（已于 2026-10 删除）

### 语音识别准不准（自测对照）

| 原话 | 识别结果 | 耗时 |
|---|---|---|
| 挖点铁回来 | 花点铁回来 | 482ms |
| 牢大 过来帮我打僵尸 | 老大过来帮我打将使 | 443ms |
| 这附近有钻石吗 | 这附近有钻石马 | 432ms |

识别引擎是 Windows 自带的中文听写，错一两个字是常态；大脑一般能猜对意思，
而且「老大」本来就在唤醒词里（牢大/老大/肘/曼巴/what can i say）。

### 为什么不让 ffmpeg 转码

语音插件默认用 ffmpeg 把音频转成 PCM。实测：**5.87 秒的音频转了 7.5 秒**（0.85 倍实时 —— 对话会卡成幻灯片）。
所以我们让它直接把话说成 48k/单声道/16bit，跳过转码，只剩 opus 那 310ms。

### 复读治好了没（拿自己的运行日志当证据）

第一轮修的是「整句话重复」，修完翻自己昨晚的日志，发现**还是像复读机**：

- 19:42–19:44 那两分钟里，大脑被叫醒 **24 次**（他在砍树，每捡起一个木头触发一次）
- 24 句里 **18 句**以「收到 man，」开头，正文全是同一个进度换个说法

```
收到 man，木头凑到 8 根了，再补几根就出石镐。
收到 man，正补木头呢——木料一够就出石镐。Mamba out!
收到 man，东北那两棵树我包了，凑够 16 根直接出石镐！
```

所以第二轮又补了三条：触发器各自带冷却（"他刚干了什么"改成两分钟一次）、
任务在跑时"捡到任务要的东西"不算新闻、以及**开场白用两次以上就拦**
（字面不同但形状一样的复读，靠字面比对是抓不住的）。

同一个场景真跑 6 次唤醒：

| 唤醒 | 修之前 | 修之后 |
|---|---|---|
| 1 | 「收到 man，…出石镐」 | 「砍得挺顺啊兄弟，48 了，我这边接着干」 |
| 2 | 「收到 man，…出石镐」 | 「48 了，这树倒得比我出手还快，Mamba out!」 |
| 3–6 | 每句都是「收到 man，…出石镐」 | 一句「他在那边一棵我一棵，看谁先把这林子清空」，其余**全程安静** |

而且**身体一次都没出手拦** —— 是它自己想明白的，硬拦只是兜底。

再往前的第一轮：同一个砍树任务连着叫醒 3 次，再问它同一句话 2 次。

| 唤醒 | 修之前（真实历史里就这样） | 修之后 |
|---|---|---|
| 心跳 1 | 「砍树任务还在跑，不吭声了。」 | **没说话** |
| 心跳 2 | 「砍树任务在跑，闷头干活，不吭声了。」 | **没说话** |
| 心跳 3 | 「砍树任务还在跑，不吭声了。」 | 「48/128，橡木进度条走着呢，man。你那边干啥呢？」 |
| 问它 1 | — | 「砍树呢兄弟，48/128，铁斧都砍热了。」 |
| 问它 2 | — | 「铁斧都抡冒烟了。」（自己换了说法，没复读） |

三件事一起改的：

1. **任务在跑时心跳根本不叫醒它** —— 做完 goal-runner 自己会来报，中途每 45 秒叫一次纯属逼它说话。
2. **「你结尾写的文字玩家看不见」写进了提示词** —— 它以前以为自己在回答，其实是在自言自语，
   所以才会一遍遍「汇报」自己在保持安静。
3. **身体硬拦重复** —— 5 分钟内说过的、或者只差一个「了」的，直接不发（阈值定得高，
   「我去挖矿」和「我去砍树」不会被误判成同一句）。

### 它会不会像人一样聊天（真 DeepSeek）

以前它闲下来只有一条路：被提示「自由活动」→ **去排活干**；被叫醒 → **汇报进度**。
「聊天」这件事根本不在它的选项里 —— 所以才有那种"只干活不说话"的打工机器人感。

现在闲下来有两种心情**轮流来**：

- **干活**：自己找活干（原来只有这一种）
- **陪聊**：不排活，就在你旁边搭话 —— 提示词里明说「别汇报进度、别列计划、别报数据」

给它一个"陪他一会儿"的提示（天黑了、你在挖矿、它手头没事），它说：

> 天黑了兄弟，你手上这堆石头木头够搭半间屋了 —— 今儿想干点啥？

下一拍，它看见你圆石越攒越多：

> 兄弟你这圆石都快两箱了，再挖下去我怀疑你要在地底盖个球馆 —— 说真的，今晚干点啥？

你随口抱怨一句树多，它接的是：

> 树多好啊，木头管够，随手就能搭个棚子顶夜 —— 就是天黑了，怪该出来了，你那边火把够不够？

你问它平时都玩什么：

> 我啊，白天挖矿盖房，晚上就出去肘怪 —— 别人练一小时我练四小时，你懂的。你要问我最爱的，那还得是挖到钻石那一下，爽。

四句里没有一句是进度报告，也没有一句用同一个开头。它得在你附近（24 格内）才会切成陪聊模式 ——
你不在旁边时它自己玩，不对着空气说话。

### 该问谁：查 wiki 还是问你（真 DeepSeek 跑出来的）

同一个假身体、真的 `deepseek-chat`，两个场景各唤醒一次：

| 场景 | 它实际调了 | 结果 |
|---|---|---|
| 你问「下界合金到底怎么弄」 | `wiki_notes` ×2 | 直接答：「那玩意叫远古残骸，只在下界刷，Y=8~24 那片最肥…一个区块就 1~2 团，得用钻石镐挖」「4 个碎片 + 4 个金锭 = 1 个下界合金锭，锻造台上升级」—— **一个字都没问你** |
| 你说「去那边挖点矿」 | `ask_player` | 「『那边』是哪边啊兄弟？指个方向，我这就开挖」—— 问 1 次 |

### 追问与经验（真 DeepSeek 跑出来的）

拿一个只挂了记忆模块的**假身体** + 真 MCP 服务，让真的 `deepseek-chat` 连着被唤醒 4 次，
每次都跟它说同一句模糊的话（「去那边挖点矿」）：

| 第几次 | 它实际调了 | 结果 |
|---|---|---|
| 1 | `ask_player` | 游戏里问：「哪边啊兄弟，你指个方向，我这就上」 |
| 2 | `ask_player` | 又问一次 —— 计数 2/3（它自己给这事的 topic 换了个名字，照样算同一件） |
| 3 | `chat` + `set_goal` | 不问了，自己拍板：「行，我往你视线那边去，挖到东西喊你！」 |
| 4 | `chat` | 直接说：「你往要挖的方向站一下，我跟着你走」 |

就算它头铁继续问，第 4 次也会被身体**硬拦下来** —— 那条消息根本不发出去，
它拿到的是「已经问过 3 次了，别再问，按最合理的假设开工」（单测覆盖）。

经验那一路也是真的：让它汇报「挖到 12 个粗铁、钻石没见着」，它自己调 `note_experience`
写进档案 —— 下一轮挖矿熟练度从 2/3 变成 3/4，还自己总结出一条教训：

> 一趟挖到12粗铁，钻石没见着 —— 想找钻石得往 y≈-55 深挖，带水桶和火把

把仓库内容拷到一个**没有 `node_modules`、没有 `.env`、没有 `data/`** 的干净目录后：


## 五分钟跑起来

**需要什么**：Windows、[Bun](https://bun.sh)、一个 Minecraft Java 版世界（原版即可，1.7~1.21 里 mineflayer 认识的版本）、
一个 [DeepSeek API key](https://platform.deepseek.com)（很便宜，一天几分钱）。

> **网络提示（中国大陆）**：直连 `github.com` 常常超时。可以挂代理，或用 GitHub 加速前缀来 clone，例如：
> `git clone https://githubproxy.cc/https://github.com/eason-jiang-web/kobe-laoda-minecraft-player-friend.git`
> （把前缀换成你信得过的加速服务即可；只影响下载，代码本身没区别。）

```powershell
git clone https://github.com/eason-jiang-web/kobe-laoda-minecraft-player-friend.git
cd kobe-laoda-minecraft-player-friend
bun install

Copy-Item .env.example .env
# 打开 .env，至少填这四项（大脑默认就是开着的，不用动）：
#   DEEPSEEK_API_KEY=sk-...
#   MC_VERSION=1.20.6          ← 必须和你启动的版本一字不差
#   MC_OWNER_USERNAME=你的游戏名
#   MC_BOT_USERNAME=Laoda      ← 机器人自己的名字（ASCII，3-16 位）

bun run doctor        # 自检：哪没配好它会直接说，并告诉你怎么改
```

然后：

1. 进游戏 → **Esc → 对局域网开放** → **端口填 25565**（游戏默认给的是随机的，一定要改）→ 允许作弊**开**
2. `bun run bot`（或者双击仓库里的 `牢大.cmd` / 桌面快捷方式，菜单按 `1`）

启动后终端会打出**全部指令和用法**，游戏里它会自己进来、跟你打招呼。

## 常用配置（`.env` 速查）

| 键 | 作用 |
|---|---|
| `MC_SERVER_HOST` / `MC_SERVER_PORT` | 连哪个世界。默认 `127.0.0.1:25565`（局域网世界）。**换成别人的服务器地址也能连** |
| `MC_AUTH` | `offline`（离线/局域网）或 `microsoft`（正版服 —— 第一次启动会打印设备码登录链接） |
| `MC_VERSION` | 世界版本，必须一致 |
| `MC_OWNER_USERNAME` | 它跟着谁、听谁的（硬指令只有这个人能触发） |
| `MC_WAKE_WORDS` | 哪些词算「在叫我」 |
| `MC_AUTOPLAY` | `true`＝没人理它时自己排活干（挖矿/探路/盖东西） |
| `MC_CHAT_REPLY_ALL` | `true`＝你说什么它都回，不用喊名字 |
| `MC_REPORT_ITEMS` | 攒够多少跟你报一声，如 `any_log:128,rare:10` |
| `MC_GAME_DIR` | 你的游戏目录（读中文物品名 + 自动开 op 用；不填会自动找） |
| `DEEPSEEK_API_KEY` | DeepSeek 的 key（大脑靠它思考） |
| `BRAIN_ENABLED` | 大脑开关，**默认开着**。关掉的话它照样进游戏、听指令，但不会跟你说话 |
| `BRAIN_CMD` | 大脑是什么，默认内置 DeepSeek；想换成别的 agent 就改这行 |

完整说明见 `.env.example` 里的注释，以及 **[docs/PCL_DEEPSEEK_SETUP.md](./docs/PCL_DEEPSEEK_SETUP.md)**（中文逐步教程，含排查）。

## 常用命令

```powershell
bun run doctor        # 上手自检（配完先跑这个）
bun run bot           # 启动机器人（--watch，改代码自动重启）
```

## 它是怎么搭的

**身体在游戏里，脑子在外面，中间走 MCP。**

| 部分 | 是什么 |
|---|---|
| `apps/mc-bot` | 身体：[Mineflayer](https://github.com/PrismarineJS/mineflayer) 机器人。**15Hz 快循环**（跟随、闪避、吃东西，纯代码不调模型）+ **约 4 秒慢循环**（判断"有没有值得反应的事"，有就叫醒大脑） |
| `apps/brain-deepseek` | 脑子：DeepSeek（或任何 OpenAI 兼容接口）。每次唤醒是一次带工具的对话，能读世界状态、下指令、写记忆 |
| `packages/mcp-server` | 神经：把身体的能力暴露成 MCP 工具、把世界状态暴露成 MCP 资源 |
| `packages/shared` | 类型、schema、人设提示词、进度/工程评估、价值评估、中文物品名 |
| `apps/web` | 落地页（可选，跟机器人无关） |

设计上就一条原则：**"我正在被岩浆烧"这种反射绝不能排在大模型后面**。所以快循环永不等待网络，慢循环才有模型。

想读懂代码，按这个顺序看：`apps/mc-bot/src/index.ts`（接线）→ `slow-loop/`（什么时候叫醒脑子）
→ `chat-commands.ts`（硬指令）→ `apps/brain-deepseek/src/index.ts`（脑子那一轮）。

## 常见问题

| 现象 | 原因 / 怎么办 |
|---|---|
| **它进游戏了，但一句话都不说** | 大脑没开。`.env` 里要有 `BRAIN_ENABLED=true` 和 `BRAIN_CMD=bun apps/brain-deepseek/src/index.ts`（`.env.example` 默认就是这两行）。启动横幅和 `bun run doctor` 都会直接把这条点出来 |
| `port 3001 is already in use` | 上一次的机器人还在跑。关掉那个窗口，或改 `.env` 里的 `MCP_PORT` 和 `ITTO_MCP_URL` |
| 一直说"连不上 127.0.0.1:25565" | 世界没开「对局域网开放」，或者**端口没从随机值改成 25565**。它会一直等，改好自己就进来了 |
| `#back` 说"传不过去" | 没有 op。游戏里打一次 `/op <机器人名>`，或者关掉世界双击 `给牢大开权限.cmd` |
| 版本报错 `is not a Minecraft version mineflayer can speak` | 换成它提示的那个版本，或改 `MC_VERSION` 跟你世界一致 |
| 想让它闭嘴/省钱 | `HEARTBEAT_MS=0`、`MC_AUTOPLAY=false`、`MC_CHAT_REPLY_ALL=false` |

更细的排查（含 op、皮肤）见 **[docs/PCL_DEEPSEEK_SETUP.md](./docs/PCL_DEEPSEEK_SETUP.md)** 和 **[docs/SKIN_AND_MENU.md](./docs/SKIN_AND_MENU.md)**。
